# Gonzalez & Co. — Escritório

Escritório isométrico (estilo Habbo) da **Gonzalez & Co. — Brand & Film Studio**.

Abra `index.html` no navegador. Não precisa de servidor: a logo já vem embutida no arquivo.

## Salas

Sala do Chefe, Sala de Reunião, Sala dos Funcionários, Sala de Jogos e Financeiro, além de Recepção (com mini estúdio), Copa, Banheiro e Hall dos elevadores, num andar de prédio com fachada de vidro.

## Como usar

- Clique no chão para mover o Talles; clique numa cadeira, sofá ou banquinho para sentar.
- Clique numa pessoa para ver o cargo e o que ela está fazendo.
- **Reunião geral** leva a equipe para a sala de reunião.
- Arraste para navegar, role para dar zoom; o menu lateral leva até cada sala.

`assets/` guarda a logo original e a imagem de referência do projeto.
